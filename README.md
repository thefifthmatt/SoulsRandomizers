# SoulsRandomizers

SoulsRandomizers has routines for randomizing FromSoftware games and otherwise adding
fun and/or challenging ways of replaying them. Find the mod releases on Nexus Mods:

- Elden Ring: https://www.nexusmods.com/eldenring/mods/428
- DS3: https://www.nexusmods.com/darksouls3/mods/361
- Sekiro: https://www.nexusmods.com/sekiro/mods/543

SoulsRandomizers is published under a [source-available license](LICENSE.md) which
means you can use the source code for reference purposes, but creating and distributing
your own releases or bundling randomizer with other software is not permitted. Randomizer
is *not* free (libre) software or open source in FSF's terminology, but it will always
be free (gratis) to use. See the license for further reasoning for this and detailed terms.

From 2019 to 2026, contributions to randomizer were not accepted, but they now are under
[contributing guidelines](https://github.com/thefifthmatt/SoulsRandomizers/blob/master/CONTRIBUTING.md)
in order for other modding projects to interoperate with randomizer or to make personal
changes more widely available, so long as you are okay with the license terms for it.
By default this would be under the [Contributor License Agreement (CLA)](https://cla-assistant.io/thefifthmatt/SoulsRandomizers)
but some contributions can alternatively be made to freely licensed dependencies.
